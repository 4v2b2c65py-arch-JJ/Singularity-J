# boundary_test

Reference implementation of the validation harness for the
**Boundary Contract v1.0.1** between `formation.py` and
`Singularity-J`.

This directory contains the small experiments that proved the
boundary contract is real, not theoretical. They are not part of the
Singularity-J runtime. They live here so a future reader can re-run
the same validation against any compatible formation source.

## Files

| File | Purpose |
|---|---|
| `BOUNDARY_CONTRACT.md` | The contract spec (rooted at `../BOUNDARY_CONTRACT.md` in the validated workspace; copied here for self-containment). |
| `python_producer.py` | Runs `formation.py` once, builds a contract-conforming envelope, writes JSON. |
| `node_consumer.js` | Reads the envelope, validates shape + types + boundary invariants. No Singularity-J execution. |
| `load_singularity.js` | Indirect-eval loader for the three Singularity-J modules. Path is configurable. |
| `end_to_end.js` | Real evidence path: feeds the envelope into `incarnationBody.infer()` and asserts the resulting body. |
| `envelope.json` | Generated by `python_producer.py`. Build artifact, not committed. |
| `README.md` | This file. |

## Running

From the parent directory of this `boundary_test/`:

```
# 1. Produce the envelope
python3 boundary_test/python_producer.py boundary_test/envelope.json 12345

# 2. Validate shape + types
node boundary_test/node_consumer.js boundary_test/envelope.json

# 3. End-to-end evidence path
node boundary_test/end_to_end.js
```

Expected: producer writes ~400 bytes; consumer reports PASS / OK;
end-to-end reports 22/22 PASS / OK.

## Configuration

Both scripts read environment variables so the harness is portable
across machines:

| Variable | Used by | Default |
|---|---|---|
| `FORMATION_DIR` | `python_producer.py` | parent dir of `boundary_test/` + `/TET_GOD_OF_PLAY` |
| `SINGULARITY_SRC` | `load_singularity.js` | `/Users/jjmarte/Documents/Singularity-J/src` |

Override either to point at a different formation source or a
different Singularity-J clone.
